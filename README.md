# Aakash P — Portfolio

Published at https://aakash1325.github.io/aakash-portfolio/ using GitHub Pages from `main`, repository root.

The generated HTML, CSS and JavaScript are committed, so Pages requires no build service. The page is rendered in advance and uses a small JavaScript file for project details, scroll reveals and clipboard feedback.

To edit and rebuild:

1. Install Node.js 22 or newer and run `npm install`.
2. Edit `src/page.tsx`, `src/styles.css` or `src/interactions.js`.
3. Run `npm run build`.
4. Commit source and generated `index.html`, `styles.css`, `script.js`.

Images are in `profile/` and `project-covers/`. The current one-page A4 résumé is `resume/Aakash_P_Resume.pdf`. All assets use paths compatible with the repository's GitHub Pages URL.
